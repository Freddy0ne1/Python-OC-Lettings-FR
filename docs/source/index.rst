Description du projet
---------------------

OC Lettings est une application web de gestion de locations
immobilieres developpee avec Django.

Technologies utilisees :

* Python 3.10
* Django 3.0
* Docker
* GitHub Actions CI/CD
* Render (hebergement)
* Sentry (monitoring)
